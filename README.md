## 📖 About The Project

Rock Paper Scissors is a classic hand game. You choose **Rock**, **Paper** or **Scissors**, the computer picks randomly, and the winner is decided by the rules below. Scores for both **You** and **Comp** are tracked live on the scoreboard.

This project was built to practise **DOM manipulation, event handling, random logic and responsive UI design**.

---

## ✨ Features

- 🎯 Play against the computer (random choice generation)
- 🏆 Live scoreboard for **You** vs **Comp**
- 💬 Result message after every round (win / lose / draw)
- 🖼️ Clickable image-based choices (rock, paper, scissors)
- 🎨 Clean, colourful and responsive UI
- ⚡ No frameworks, no dependencies: pure HTML, CSS and JS

---

## 🎲 Game Rules

| Your Move | Beats |
|-----------|-------|
| ✊ Rock | ✌️ Scissors |
| ✋ Paper | ✊ Rock |
| ✌️ Scissors | ✋ Paper |

Same choice dono ki ho to round **Draw** hota hai.

## 🚀 Getting Started

### Prerequisites
Sirf ek modern web browser (Chrome, Edge, Firefox, etc.). Koi installation ki zarurat nahi.

### Installation & Run

1. **Clone the repository**
   ```bash
   git clone https://github.com/sneha-goyal7/Stone-Paper-Scissor.git
   ```
2. **Go to the project folder**
   ```bash
   cd Stone-Paper-Scissor
   ```
3. **Open the game**
   - Double-click `index.html`, **or**
   - Use the **Live Server** extension in VS Code (`Right click → Open with Live Server`)

---

## 🎮 How To Play

1. Page open karo, "Play your move" message dikhega.
2. **Rock, Paper ya Scissors** mein se kisi ek par click karo.
3. Computer apna random move chunega.
4. Winner ka score badhega aur result message dikhega.
5. Jitni baar chaho khelo aur dekho kaun aage nikalta hai! 🏁
